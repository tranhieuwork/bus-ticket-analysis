# Dataset

This directory contains synthetic datasets for the Bus Ticket Analysis project.

The datasets represent a simulated bus ticket marketplace and are intended for educational and portfolio purposes only. They do not contain actual customer transactions.

## Files

- `dim_date.csv`: Date and calendar attributes.
- `dim_route.csv`: Bus routes and route information.
- `dim_operator.csv`: Bus operators and their attributes.
- `dim_customer.csv`: Simulated customer attributes.
- `dim_channel.csv`: Booking channels.
- `dim_voucher.csv`: Voucher information.
- `fact_trips.csv`: Trip schedules, seat capacity, and occupancy.
- `fact_bookings.csv`: Booking transactions, prices, discounts, and booking status.
